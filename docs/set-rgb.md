# LCD backlight red green blue

Set the backlight color by mixing red, green and blue. Stops the rainbow if it is running.

```sig
groveLcd.setRGB(255, 255, 255)
```

## Parameters

* **r**: red brightness 0-255.
* **g**: green brightness 0-255.
* **b**: blue brightness 0-255.

## Example

```blocks
groveLcd.setRGB(0, 128, 255)
```

```package
grove-lcd-rgb-v4=github:ikaros-ch/pxt-grove-lcd-rgb-v4
```
