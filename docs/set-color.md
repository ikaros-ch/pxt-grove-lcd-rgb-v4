# LCD backlight color

Set the backlight to a color from the color picker. Stops the rainbow if it is running.

```sig
groveLcd.setColor(0xff0000)
```

## Parameters

* **color**: the color, like `0xff0000` for red.

## Example

```blocks
groveLcd.setColor(0x00ff00)
```

```package
grove-lcd-rgb-v4=github:ikaros-ch/pxt-grove-lcd-rgb-v4
```
